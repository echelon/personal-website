# Spectrogram sources

The carousel uses `clean/`. The annotated images in this directory are preserved unchanged. The unwatermarked reference was already clean and is copied unchanged into both sets.

All six watermarked images in `clean/` are unmodified files from the authors’ repository, before the red rectangles were added. Each downloaded file was verified byte-for-byte against the original PNG embedded in the corresponding annotated image’s diagrams.net (`mxfile`) metadata. No inpainting, interpolation, rescaling, or pixels from another sample were used. All images remain 775 × 308 pixels.

- [Original spectrogram commit (2024-12-06)](https://github.com/SoKAudioWM/sokaudiowm.github.io/commit/84dc70e96e48d4f75f265f2d463f671389f7a73b)
- [Commit adding red boxes (2025-01-25)](https://github.com/SoKAudioWM/sokaudiowm.github.io/commit/edb9b45ff1efde44c1964ef2cb28dbdc3953693e)
- [Paper](https://arxiv.org/abs/2503.19176) and [sample page](https://sokaudiowm.github.io/)

Original files are at `audio_samples/wm/lj/{name}.png` in the December commit; `norm-space.png` is named `norm_space.png` upstream. The unwatermarked reference comes from `audio_samples/og/lj.png` in repository commit `e375e24734042ae871779edd6abaa31e9102970e`.

## Optional signal highlights

The applet draws translucent SVG regions over the clean images. The rectangle
coordinates below were extracted from the red rectangle cells in each original
PNG's `mxfile` text chunk (diagrams.net metadata), subtracting the embedded image's
canvas origin. Coordinates are `[x, y, width, height]` in the 775 × 308 image grid.
The original rounded rectangles use a radius of 20% of the shorter side.

- Unwatermarked: none
- Timbre: [7.5, 42, 760, 190]
- AudioSeal: [7.5, 184, 760, 40]
- WavMark: [250, 12, 60, 290], [470, 152, 60, 150], [80, 122, 60, 150]
- FSVC: [3, 130, 760, 40]
- Patchwork: [10, 62, 760, 110]
- Norm-Space: [460, 3, 50, 100], [250, 192, 60, 110]

These reproduce the authors' illustrative regions, not a decoded payload map.
The overlay uses a 12% amber fill, an amber outline and a thin dark outer edge.
Both original image sets remain unchanged.
